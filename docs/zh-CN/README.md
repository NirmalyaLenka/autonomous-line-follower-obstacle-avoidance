## 项目概述

这是一个基于 ESP32 的黑白线循迹与障碍物绕行机器人。固件使用数字红外传感器读取循迹状态，使用 VL53L0X 兼容的 ToF 模块测量前方距离，并通过电机驱动板控制左右直流减速电机。

当前固件包含 PD 风格的循迹控制和基于时间的避障状态机。避障动作依赖机器人右侧有足够的可通行空间；这不是经过验证的全向或自主路径规划系统。

## 重要提醒

- 在给电路上电之前，请先核对实际模块的引脚、供电范围和接线。
- ESP32 GPIO **不耐受 5 V 输入**。不要将 5 V 信号直接接入 ESP32 GPIO。
- 电机电源与逻辑电源应按驱动板要求连接，并确保共地。
- 如果 ToF 模块初始化失败，当前固件可能仍继续循迹，但会禁用避障功能。测试时不要让机器人在有人、楼梯或易损设备附近高速运行。
- 仓库文档记录了 IR1 存在缺陷，但当前固件仍会读取它。请查看“代码与说明差异”及校准指南，不要假设所有传感器都可靠。
