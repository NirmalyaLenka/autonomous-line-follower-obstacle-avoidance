# 安装、编译与串口命令

## 1. 准备软件

1. 安装 Arduino IDE。
2. 在开发板管理器中安装 ESP32 开发板支持包。
3. 在“工具 → 开发板”中选择与硬件相符的 ESP32 Dev Module。
4. 根据固件的 include 语句和仓库说明安装所需库，尤其检查 VL53L0X 兼容 ToF 传感器库。
5. 下载或克隆本仓库，打开 `src/main.ino`。

不同版本的 ESP32 核心和传感器库可能存在兼容性差异。若编译报错，先保存完整错误信息并核对库版本，不要随意更改引脚或控制逻辑。

## 2. 编译与上传

1. 先断开机器人驱动电源，只连接 ESP32 USB。
2. 选择正确的开发板和串口端口。
3. 点击“验证/编译”，确认没有编译错误。
4. 上传固件。若失败，检查 USB 数据线、端口、驱动和开发板选择。
5. 上传成功后打开串口监视器，波特率设为 **115200**。
6. 检查启动信息和传感器读数，再抬起车轮进行电机测试。

## 3. 串口命令

| 命令 | 用途 |
|---|---|
| `h` | 显示帮助 |
| `s` | 启动/停止 |
| `c` | 校准 |
| `d` | 调试信息 |
| `t` | 电机测试 |
| `v` | 读取 ToF 距离 |
| `i` | 读取红外传感器 |
| `g` | 显示几何参数 |
| `r` / `l` | 右转 / 左转测试 |
| `f` | 偏移测试 |
| `p` | 通过测试 |
| `o` | 绕行测试 |

如果命令无响应，先发送 `h` 查看固件帮助文本，并检查串口波特率和端口。串口监视器的换行设置应与固件解析方式相符。

## 4. 首次运行顺序

- [ ] 检查供电、共地和 GPIO 接线。
- [ ] 确认串口能显示启动信息。
- [ ] 使用 `i` 检查红外传感器。
- [ ] 使用 `v` 检查 ToF 距离读数。
- [ ] 车轮离地时执行 `t`，确认左右电机方向。
- [ ] 在低速、无遮挡的短直线上测试循迹。
- [ ] 最后才在低速、可控环境中测试避障。

**注意：** ToF 初始化失败时，当前固件可能关闭避障但继续循迹。机器人仍在移动并不代表避障正常。
