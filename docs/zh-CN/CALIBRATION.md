# 校准指南

请按顺序校准。每次只改变一个因素并记录结果，否则难以判断问题来自传感器、接线还是控制参数。

## 1. 红外循迹传感器

1. 将机器人抬起或固定，避免电机意外启动。
2. 打开串口监视器（115200），发送 `i` 查看各通道状态。
3. 分别将每个传感器对准黑线和白底，确认输出稳定且两种状态有明显区别。
4. 调整传感器高度和角度，避免反光、环境光和底盘晃动影响读数。
5. 特别检查 IR1：仓库记录该通道存在缺陷，但固件仍会读取它。不要默认其读数可信。

不同数字传感器模块的输出极性可能不同。不要假设 LOW 一定代表黑线；请以实测和固件逻辑为准。

## 2. 电机方向与速度

1. 先让车轮离地。
2. 发送 `t` 进行电机测试。
3. 确认左右电机的前进方向一致，并检查方向引脚和电机接线。
4. 如果方向相反，先核对接线和固件逻辑；不要在电机通电时插拔导线。
5. 从低速开始，检查电源压降、驱动板温升和 ESP32 是否重启。

## 3. ToF 距离传感器

1. 确认 SDA=GPIO21、SCL=GPIO22，且模块供电与逻辑电平兼容。
2. 发送 `v`，将平整目标放在已知距离处比较读数。
3. 检查读数稳定性，并确认视野没有被车身或线缆遮挡。
4. 当前阈值为停止距离 300 mm、紧急距离 250 mm。这些是代码参数，不代表机器人一定能在该距离内安全停下。
5. 若传感器初始化失败，不要继续测试避障。

## 4. 几何参数

当前代码参数：

- `ROBOT_LENGTH_MM = 250`
- `ROBOT_WIDTH_MM = 190`
- `OBSTACLE_STOP_MM = 300`
- `OBSTACLE_EMERGENCY_MM = 250`
- `GEOMETRY_MEASURED = false`

250 mm 长、190 mm 宽是代码中的数值；由于 `GEOMETRY_MEASURED = false`，不能把它们视为已完成实测验证。发送 `g` 查看固件报告的几何信息。

## 5. 循迹控制与避障

- 先在直线、低速和稳定光线下检查循迹，再逐步测试弯道。
- 若机器人左右摆动，先检查传感器读数、安装位置和电机方向，再考虑调整控制参数。
- 当前循迹采用 PD 风格逻辑。建立基线前不要同时修改多个参数。
- 避障使用基于时间的状态机，并假设右侧有可通行空间。请在低速、无人且有边界的测试区验证。
- 每次修改后记录版本、测试条件和结果，以便恢复之前可用的配置。
