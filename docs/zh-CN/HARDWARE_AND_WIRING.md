# 硬件与接线

本指南根据仓库现有硬件说明与 `src/main.ino` 中的引脚定义整理。**实际接线前，请以手中模块的丝印和电路板版本为准。**

## 主要器件

- ESP32 Dev Module
- TB6612FNG 双路直流电机驱动板
- 两个 BO 减速直流电机
- 7 路数字红外循迹传感器（IR1–IR7）
- VL53L0X 兼容 ToF 距离传感器
- 标称 7.4 V 电池及符合负载要求的降压模块

## ESP32 引脚分配

| 功能 | ESP32 GPIO |
|---|---:|
| IR1 | 14 |
| IR2 | 13 |
| IR3 | 16 |
| IR4（中心/参考） | 17 |
| IR5 | 18 |
| IR6 | 19 |
| IR7 | 23 |
| 左电机 PWM | 25 |
| 左电机方向输入 | 26、27 |
| 右电机 PWM | 32 |
| 右电机方向输入 | 33、4 |
| TB6612FNG STBY | 5 |
| ToF SDA | 21 |
| ToF SCL | 22 |

电机方向输入与驱动板 AIN/BIN 的对应关系，请结合固件定义和实际接线再次确认，不要只凭表格猜测电机端子顺序。

## 接线检查

1. ToF 的 SDA 接 GPIO21、SCL 接 GPIO22，并确认模块逻辑电平兼容。
2. 将 7 路红外传感器输出分别接到表中 GPIO。
3. 按固件定义连接左右电机 PWM、方向输入和 STBY。
4. 按 TB6612FNG 模块标注连接逻辑电源、马达电源和电机端子。
5. 按电池与降压模块规格供电；ESP32、传感器和驱动逻辑部分应共地。
6. 首次通电前检查短路、极性和松动导线。

## 电源与安全

- ESP32 GPIO **不耐受 5 V 输入**。若传感器输出为 5 V，必须使用合适的电平转换。
- 不要将电机直接连接到 ESP32 GPIO。
- 电机启动或堵转电流可能导致电源压降、ESP32 重启或驱动板过热。电源、导线和连接器必须能承受实际电流。
- 不要把电池正极直接接到 ESP32 的 3.3 V 引脚。
- 改线前先断电；测试时固定机器人并远离车轮。

## 已知限制

仓库记录 IR1 存在缺陷，但固件仍会读取该通道。不要假设 IR1 的读数可信；校准时应单独检查每个通道。
