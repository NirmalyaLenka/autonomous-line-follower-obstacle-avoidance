# 代码与硬件说明差异记录

本文件整理已记录的代码与项目说明之间需要注意的差异。它用于披露已知事项，不会自动修复代码或改变硬件。

## 1. IR1 通道存在缺陷

项目资料记录 IR1 有缺陷，但当前固件仍读取 GPIO14 对应的 IR1 通道。因此，调试输出出现该通道读数，并不代表传感器已经修复或经过验证。

## 2. 几何参数未标记为实测

当前固件参数：

- `ROBOT_LENGTH_MM = 250`
- `ROBOT_WIDTH_MM = 190`
- `GEOMETRY_MEASURED = false`

250 mm 长、190 mm 宽是代码中使用的参数，但标志位表明几何数据未被标记为实测确认。请使用实物测量并验证，不能仅凭代码常量认定尺寸准确。

## 3. 避障阈值不等于保证的制动距离

当前代码使用停止距离 300 mm 和紧急距离 250 mm。实际停车距离受速度、负载、地面摩擦、供电和程序延迟影响。必须在受控环境中实测；不要把阈值当作安全保证。

## 4. 避障依赖定时动作与右侧空间

当前避障逻辑采用基于时间的状态机，并假设右侧有可通行空间。它不是对整条路径进行实时感知和验证的通用自主导航系统。狭窄、复杂或陌生的场地可能导致碰撞。

## 5. ToF 初始化失败时的行为

如果 ToF 初始化失败，当前固件可能禁用避障但继续执行循迹。测试前应确认 ToF 正常工作；机器人仍然移动不代表避障可用。

## 修改建议流程

1. 记录硬件接线、固件版本和可复现的问题。
2. 通过串口命令检查红外传感器、ToF 和电机。
3. 一次只修改一个参数或功能。
4. 在低速、封闭、无人环境中重复测试。
5. 将已验证的行为、实测值和限制写入项目资料。
